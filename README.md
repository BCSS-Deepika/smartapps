# SMARTAPPS by Blue Cloud Softech Solutions

Static portfolio website for the SmartApps portfolio: Access Genie (with the GARUDA policing ecosystem, Retail and BluGo), Blura SAGA and EduGenie COE.

- `index.html` — portfolio home
- `products/` — one page per product, each with a module explorer (every module has its own link, e.g. `products/smartcop.html#m-frs`)
- `demos/` — interactive architecture demos, linked from their product pages

Plain HTML, no build step. To host with GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
